# Project 1: Responsive Frontend Interface (Hearth Tasks)

A responsive task management interface built using pure HTML5, CSS3, and vanilla JavaScript. No frameworks required.

## Run

Open `index.html` in your browser, or run:

```bash
npx serve .
```

## Features & Project Checklist

- **Semantic HTML5:** Header, nav, main, section, article, aside, and footer.
- **Responsive Design:** Mobile-first layout with breakpoints at 768px and 1024px.
- **Modern CSS:** CSS Grid, Flexbox, and clamp() for fluid typography.
- **Color Palette:** Mocha Mousse, Ethereal Blue, and Moonlit Grey.
- **Typography:** Montserrat and Open Sans.
- **JavaScript Functionality:** Add, complete, delete, and filter tasks.
- **Local Storage:** Tasks are saved in the browser using localStorage.
- **Accessibility:** Skip links, labels, aria-live, visible focus indicators, and reduced-motion support.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
