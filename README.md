# Project 1: Responsive Frontend Interface (Hearth Tasks)
Pure HTML5, CSS3 and vanilla JavaScript. No frameworks.

## Run
Open `index.html` in a browser (or `npx serve .`).

## Brief checklist
- Semantic landmarks: header, nav, main, section, article, aside, footer
- Mobile-first: single column, then min-width queries at 768px and 1024px
- CSS Grid for macro layout, Flexbox for components, clamp() for fluid type
- Palette: Mocha Mousse, Ethereal Blue, Moonlit Grey. Fonts: Montserrat + Open Sans (2 families, 3 weights)
- JavaScript: add / complete / delete / filter tasks, saved in localStorage
- Accessibility: skip link, labels, aria-live, visible focus, 44px touch targets, reduced-motion
- Audit: run Lighthouse in Chrome DevTools (LCP/CLS, Accessibility)
